# Asset Vault · 数字资产中心

一个**本地优先、加密存储**的 Windows 桌面密码/数字资产库。数据只保存在你自己的电脑上，用主密码派生密钥加密，支持备份/恢复、跨设备迁移、AI 辅助写入审批。

> 本仓库是**公开发布快照**：仅包含可公开的产品代码与使用文档。完整开发历史保留在作者的私有仓库中。

## 功能特性

- 🪟 **独立桌面窗口**：基于 pywebview（EdgeChromium），无浏览器地址栏、无控制台黑窗，关窗即锁库并停止本地服务
- 🔐 **本地加密**：主密码 → PBKDF2（60 万轮）→ KEK → 包裹 DEK；敏感字段加密落盘，明文绝不写入数据库
- 💾 **备份与恢复**：每次业务变更自动备份，整库快照 `.avbak`；空环境可仅凭备份 + 主密码完整恢复
- 💻 **跨设备迁移**：第二台无开发环境的 Windows 机器，用 U 盘备份即可恢复（已实测）
- 🔑 **自行修改主密码**：改前自动备份，KEK 重包、DEK 不变，历史备份仍用导出时密码
- 🤖 **AI 总开关与审批**：AI 默认关闭；开启需明确风险提示确认，AI 提交一律进入人工审批后才写入
- 🗂️ **优先级与到期日**：过期/临期自动排序标识，纯前端计算、不改写任何已存字段
- 🧹 **删除全部数据**：设置页危险操作，勾选 + 输入 DELETE 双确认

## 系统要求

- Windows 10 / 11（64 位）
- Microsoft Edge **WebView2 运行时**（多数新版 Win10/11 已自带；缺失时程序会提示，可到微软官网下载 Evergreen 版安装）
- **无需安装 Python、无需命令行**

## 下载与使用（绿色免安装）

1. 在 [Releases](../../releases) 下载 `AssetVault-green-v0.1.1.zip`，解压到任意文件夹
2. 双击其中的 **`AssetVault.exe`**
   - 未签名程序可能出现 SmartScreen：点「更多信息」→「仍要运行」
3. 首次启动二选一：
   - **初始化新库**：设置 6 位数字主密码
   - **从备份恢复已有库**：选择 `.avbak` 备份文件，输入导出时的主密码
4. 之后每次启动输入主密码即可使用

> ⚠️ **主密码遗失无法找回**，请妥善记忆/抄写保存。数据目录在程序旁的 `data/` 下，请定期备份该目录或导出 `.avbak`。

## 从源码运行（开发者）

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt -r requirements-desktop.txt
python -m desktop.app_main
```

- 桌面入口：`desktop/app_main.py`
- 浏览器开发入口：`app/main.py`（Flask + 本地服务）

## 数据与安全说明

- 所有数据仅存储在本机 `data/vault.db`，敏感字段加密，主密码/KEK/DEK 只存在于内存会话
- 备份为整库加密快照，导出时的主密码用于恢复；请像保管数据库一样保管备份文件
- 本程序不主动联网；AI 功能只有在你明确开启并提交时才与相应服务交互
- 未购买代码签名证书，Windows 可能提示未知发布者
